# AI图谱应用

AI图谱应用是一个面向个人学习和职业方向规划的桌面端学习助手。项目基于 React、Express 和 Electron，把课程学习、资料库、知识图谱、岗位资讯爬取、AI 答疑和本地知识库检索整合到一个 Windows 应用里。

## 核心功能

- 桌面端程序：使用 Electron 封装，打开后是独立窗口，不依赖浏览器地址栏。
- AI 答疑：支持本机 Ollama 或 OpenAI 兼容供应商接口，用户可以在设置页自行填写模型地址、模型名和 API Key。
- 知识库增强回答：可检索数据库资料、笔记和课程资料，并在回答中显示引用来源。
- 带权检索词：当没有独立向量模型时，问答模型会先生成带权检索词，再由本机对资料分块评分。
- 岗位资讯发现：根据目标岗位抓取技术资讯、开源项目和学习方向信息，辅助规划下一步学习。
- 本地资料管理：支持课程、笔记、数据库资料、历史记录和知识图谱等学习数据管理。

## 环境要求

- Windows 10/11
- Node.js 20 或更高版本
- npm

下载地址：[Node.js 官网](https://nodejs.org/)

## 本地运行

```bash
npm install
npm run dev
```

运行后访问 `http://127.0.0.1:5173`。

## 启动桌面程序开发版

```bash
npm run desktop
```

这个命令会先构建前端，然后打开 Electron 桌面窗口。

## 打包 Windows 程序

```bash
npm run package:desktop
```

打包结果会输出到 `release` 文件夹。当前配置生成免安装版，适合比赛演示和提交。

## 大模型接口配置

进入应用后打开“设置”页面，在“模型与提示词”里配置：

- 本机 Ollama：基础地址通常为 `http://127.0.0.1:11434/v1`，模型名填写本机已下载模型。
- 供应商接口：选择 OpenAI 兼容接口，填写供应商的 Base URL、模型名和 API Key。
- 检索方式：默认使用“问答模型生成带权检索词”，无需额外向量模型；也可以切换到独立嵌入模型。

项目不会把真实 API Key 写入源码仓库。`.env.example` 只提供邮件服务示例配置。
